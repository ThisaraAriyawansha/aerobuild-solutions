# 🏗️ Aerobuild Solutions - Construction Company Website

A **modern construction company website** built to professionally showcase projects, clients, and services.  
The platform includes a **React + Tailwind CSS** public frontend and a **Laravel + MySQL** powered admin panel for complete project management.

---

## 🚀 Tech Stack

**Frontend:**
- React.js
- Tailwind CSS
- Axios
- React Router DOM

**Backend:**
- Laravel (PHP)
- MySQL
- RESTful API Architecture

**Hosting / Deployment:**
- Vercel (Frontend)
- cPanel / Laravel Server (Backend)
- MySQL Database

---

## 🏢 Overview

Aerobuild Solutions is a **full-stack construction company web application** designed to showcase the company’s portfolio and manage construction projects efficiently.  
The **public website** highlights services and completed projects, while the **admin dashboard** allows administrators to manage clients, categories, images, videos, and project statuses.

---

## ✨ Key Features

### 🖥️ Public Website
- Responsive and elegant frontend built with React and Tailwind CSS  
- Interactive gallery of construction projects with images and videos  
- Filter projects by category or status  
- SEO-optimized structure and modern animations  

### ⚙️ Admin Panel (Laravel)
- Secure admin authentication and session management  
- Add, update, and delete projects  
- Manage project categories and client data  
- Upload multiple project images and videos  
- Manage project status (Ongoing, Completed, Upcoming)  
- Simple and clean dashboard UI for administrators
